## Obsidian Plugin Workflow

For Obsidian plugin work:
- Edit source in this repo first, usually under `obsidian/plugins/<plugin-name>/`.
- Do not treat the live vault plugin folder as the source of truth.
- Build from the source project, typically with that plugin's local build command.
- Sync built artifacts into the live vault plugin directory at `/Users/chaintng/Library/Mobile Documents/iCloud~md~obsidian/Documents/obsidian-notes/.obsidian/plugins/<plugin-id>`.
- For local plugin updates, usually copy `main.js`, `manifest.json`, and `styles.css` into the vault plugin folder after a successful build.

## Search And Editing Hygiene

- Prefer narrow `rg` searches by filename, script name, directory name, or workflow term.
- When a task mentions CapCut, check the draft and export directories above before assuming content lives inside this repository.
- When a task mentions notes, content, KaoJai context, or Obsidian plugins, search the vault root directly instead of mirrored copies elsewhere.
